# Metod-prostyx-realizacix
# Документация к программе решения нелинейного уравнения методом простых итераций

## 1. Описание программы

### 1.1. Назначение

Программа представляет собой консольное приложение на языке **Java**, предназначенное для приближённого решения нелинейного уравнения вида

\[
f(x) = 0
\]

**методом простых итераций**.

В качестве конкретного уравнения используется кубическое уравнение:

\[
f(x) = x^3 - x - 2 = 0
\]

Корень уравнения ищется на отрезке \([a; b]\), по умолчанию \([1;\ 2]\), с точностью \(\varepsilon = 0{,}0001\).

---

### 1.2. Математическая основа

#### Исходное уравнение

\[
x^3 - x - 2 = 0
\]

#### Приведение к итерационному виду

Уравнение преобразуется к эквивалентному виду \(x = \varphi(x)\):

\[
x^3 = x + 2 \quad \Rightarrow \quad x = \sqrt[3]{x + 2}
\]

Итерационная функция:

\[
\varphi(x) = \sqrt[3]{x + 2}
\]

#### Проверка условия сходимости

Для сходимости метода простых итераций необходимо, чтобы в окрестности корня выполнялось условие:

\[
|\varphi'(x)| < 1
\]

Производная итерационной функции:

\[
\varphi'(x) = \frac{1}{3\sqrt[3]{(x + 2)^2}}
\]

На отрезке \([1;\ 2]\):

| Точка | Значение \(|\varphi'(x)|\) |
|---|---|
| \(x = 1\) | \(\approx 0{,}21\) |
| \(x = 2\) | \(\approx 0{,}16\) |

Условие сходимости выполняется на всём отрезке — метод сходится.

---

### 1.3. Основные возможности программы

Программа позволяет:

1. **Задавать входные параметры** через консоль или прямо в коде:
   - левую границу отрезка \(a\);
   - правую границу отрезка \(b\);
   - точность вычислений \(\varepsilon\);
   - начальное приближение \(x_0\);
   - максимальное количество итераций \(n\).

2. **Использовать значения по умолчанию**, если пользователь не ввёл данные:
   - \(a = 1{,}0\);
   - \(b = 2{,}0\);
   - \(\varepsilon = 0{,}0001\);
   - \(x_0 = 1{,}5\);
   - \(n = 100\).

3. **Проверять корректность отрезка** — программа предупреждает, если на концах отрезка функция не меняет знак (тогда корня на этом отрезке может не быть).

4. **Проверять условие сходимости** метода: \(|\varphi'(x_0)| < 1\). Если условие не выполнено, выводится предупреждение о возможном расхождении итераций.

5. **Выводить пошаговую таблицу итераций**:
   - номер итерации;
   - текущее приближение \(x_k\);
   - новое приближение \(x_{k+1} = \varphi(x_k)\);
   - модуль разности \(|x_{k+1} - x_k|\).

6. **Автоматически останавливать вычисления**, когда:
   - достигнута заданная точность \(\varepsilon\);
   - или исчерпано максимальное число итераций \(n\).

7. **Выводить итоговый результат**:
   - найденный приближённый корень;
   - значение функции \(f(x)\) в этой точке (контроль близости к нулю);
   - количество выполненных итераций.

---

### 1.4. Структура программы

Программа состоит из четырёх основных частей:

| Часть | Назначение |
|---|---|
| `f(x)` | Вычисление значения функции \(f(x) = x^3 - x - 2\) |
| `phi(x)` | Итерационная функция \(\varphi(x) = \sqrt[3]{x + 2}\) |
| `simpleIteration(x0, eps, maxIter)` | Реализация метода простых итераций |
| `main()` | Ввод данных, проверка условий, запуск метода |

---

### 1.5. Ограничения и особенности

- Метод простых итераций сходится только при выполнении условия \(|\varphi'(x)| < 1\) в окрестности корня.
- Скорость сходимости — **линейная** (медленнее, чем у метода Ньютона).
- При неудачном выборе итерационной функции \(\varphi(x)\) метод может расходиться.
- Функция \(\sqrt[3]{x + 2}\) определена при любых значениях \(x\), поэтому ограничений по области определения нет.
- Точность \(\varepsilon\) задаётся как модуль разности двух соседних приближений: \(|x_{k+1} - x_k| < \varepsilon\).

## 2. Описание алгоритма

### 2.1. Метод простых итераций

#### Идея метода

Уравнение \(f(x) = 0\) приводится к эквивалентному виду \(x = \varphi(x)\). Затем строится итерационная последовательность:

\[
x_{k+1} = \varphi(x_k)
\]

Если \(|\varphi'(x)| < 1\) в окрестности корня, последовательность сходится к корню \(x^*\).

#### Формула для нашей задачи

\[
x_{k+1} = \sqrt[3]{x_k + 2}
\]

#### Пошаговый алгоритм

1. Ввести начальное приближение \(x_0\), точность \(\varepsilon\), максимум итераций \(n\).
2. Положить \(k = 0\), \(x = x_0\).
3. Вычислить \(x_{\text{new}} = \varphi(x) = \sqrt[3]{x + 2}\).
4. Если \(|x_{\text{new}} - x| < \varepsilon\) — корень найден, перейти к шагу 7.
5. Иначе \(x = x_{\text{new}}\), \(k = k + 1\).
6. Если \(k < n\) — вернуться к шагу 3; иначе — вывести сообщение, что точность не достигнута.
7. Вывести \(x_{\text{new}}\) как приближённый корень.

#### Блок-схема (текстовая)

```
    ┌─────────────────────┐
    │ Ввод x0, ε, n       │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ k = 0, x = x0       │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ x_new = φ(x)        │
    │   = (x + 2)^(1/3)   │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ |x_new - x| < ε ?   │─── да ──► Вывод корня x_new
    └──────────┬──────────┘
               │ нет
               ▼
    ┌─────────────────────┐
    │ x = x_new           │
    │ k = k + 1           │
    └──────────┬──────────┘
               ▼
    ┌─────────────────────┐
    │ k < n ?             │─── да ──► (наверх к вычислению φ(x))
    └──────────┬──────────┘
               │ нет
               ▼
    ┌─────────────────────┐
    │ Вывод: не сошлось   │
    └─────────────────────┘
```

---

### 2.2. Условие сходимости

Метод простых итераций сходится, если:

\[
|\varphi'(x)| < 1 \quad \text{на отрезке } [a; b]
\]

В нашей задаче:

\[
\varphi'(x) = \frac{1}{3\sqrt[3]{(x + 2)^2}}
\]

Максимум модуля на \([1;\ 2]\) достигается в точке \(x = 1\):

\[
|\varphi'(1)| = \frac{1}{3\sqrt[3]{9}} \approx 0{,}21 < 1
\]

Условие выполнено — метод сходится.

---

### 2.3. Оценка погрешности

**Критерий остановки:**

\[
|x_{k+1} - x_k| < \varepsilon
\]

**Апостериорная оценка погрешности:**

\[
|x_k - x^*| \le \frac{|\varphi'(x)|}{1 - |\varphi'(x)|} \cdot |x_k - x_{k-1}|
\]

где \(x^*\) — истинный корень уравнения.

---

### 2.4. Сравнение с другими методами

| Критерий | Простые итерации | Метод Ньютона | Метод Хорд |
|---|---|---|---|
| **Скорость сходимости** | Линейная | Квадратичная | Линейная |
| **Нужна производная** | Нет (только \(\varphi'\) для проверки) | Да | Нет |
| **Входные данные** | Начальное приближение \(x_0\) | \(x_0\) | Отрезок \([a; b]\) |
| **Число итераций (пример)** | ~5 | ~4 | ~18 |
| **Простота реализации** | Очень простая | Средняя | Средняя |
| **Условие сходимости** | \(|\varphi'(x)| < 1\) | Удачный выбор \(x_0\) | Смена знака \(f(a) \cdot f(b) < 0\) |

Для данного уравнения метод простых итераций сошёлся за **5 итераций** — это немного медленнее метода Ньютона, но значительно проще в реализации и не требует вычисления производной исходной функции.
